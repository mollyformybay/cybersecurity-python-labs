# Лабораторна робота №2. Розробка консольних утиліт для задач кібербезпеки

## Варіант 15: Аудитор логів використання привілейованих команд (Sudo / Privileged Access)

### 1. Структура файлів варіанта
Вхідні файли розміщено в підкаталозі `labs/lab02/data/data_v15/`:
* `sudo.log` — журнал подій виклику утиліти `sudo` (часові мітки ISO 8601, імена користувачів, TTY, робочі директорії, цільові користувачі та виконані команди).
* `alert_commands.txt` — словник сигнатур/патернів підозрілих або високризикових команд (наприклад: `chmod 777`, `nc`, `nmap`, `dd`, `/etc/shadow`).
